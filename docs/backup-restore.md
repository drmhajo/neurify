# النسخ الاحتياطي والاستعادة

ميزة النسخ الاحتياطي مخصصة للمشرف في نسخة العرض الحالية. تنشئ حزمة JSON تحتوي على بيانات القسم المحفوظة محلياً، ويمكن استيراد حزمة مدعومة لاستبدال بيانات العرض بعد تأكيد صريح.

| الوظيفة | السلوك الحالي |
| --- | --- |
| تصدير النسخة | ينشئ ملف JSON ويعرض خيارات الحفظ أو المشاركة في الجهاز، أو ينزّله في الويب. |
| التحقق عبر API | مسار إداري يتحقق من بنية الحزمة قبل اعتمادها في التكاملات المؤسسية. |
| الاستعادة | تستبدل بيانات العرض المحلية فقط بعد تأكيد المشرف. |
| المرفقات | تحفظ المراجع إلى المرفقات المحلية؛ لا تنقل الملفات الفعلية بين الأجهزة. |

> لا تمثل هذه الميزة بديلاً عن النسخ المؤسسي المشفّر أو سجلات التدقيق أو سياسات الاحتفاظ المعتمدة. يجب ربطها بهوية مؤسسية وتخزين مركزي محمي قبل استخدامها مع بيانات مرضى فعلية.
