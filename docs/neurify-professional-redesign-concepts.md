# Neurify Professional Redesign Concepts

The five replacement boards use a stricter enterprise design standard than the earlier concepts. Each board shows the same four high-value workflows—Today, Medical record, Report request, and the administrator Overdue reports monitor—so the visual systems can be compared without changing Neurify's functional scope.

| Concept | Design system | Best fit |
| --- | --- | --- |
| 01 — Executive Clinical | Off-white, midnight navy, and restrained emerald; generous whitespace and precise hierarchy | Recommended for the most balanced hospital-wide experience |
| 02 — Precision Grid | White, graphite, cobalt, and a rigorous editorial grid | Best for high information density and rapid scanning |
| 03 — Riyadh Health | Pale sand, deep teal, royal navy, and minimal muted-gold priority markers | Best for a distinctive Saudi institutional identity |
| 04 — Night Operations | Low-glare navy, blue-gray, cyan actions, and restrained urgency colors | Best for on-call and low-light clinical use |
| 05 — Calm Institutional | Porcelain, desaturated blue-green, deep ink, and subtle burgundy alerts | Best for a calm, mature, approachable system |

All concepts retain English as the default language with bilingual Arabic support, safe spacing around camera cutouts and gesture areas, role-aware administrative workflows, and de-identified demonstration content. They are visual mockups only; choosing one does not change the underlying permissions, synchronization, reporting, or notification behavior.
