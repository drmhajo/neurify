# حفظ مرفقات الجداول والأشعة

تعمل المرفقات في النسخة الحالية **محلياً على جهاز المستخدم**. عند اختيار إجراء الحفظ من جدول المناوبات أو التوزيع الأسبوعي أو مرفقات الأشعة، ينشئ التطبيق نسخة محلية مؤقتة ثم يعرض خيارات نظام الجهاز ليختار المستخدم موقع الحفظ أو التطبيق المستلم.

| المنصة | السلوك الحالي |
| --- | --- |
| iOS وAndroid | تُجهَّز نسخة محلية ثم تظهر واجهة النظام للحفظ أو المشاركة. |
| معاينة الويب | لا يمكن حفظ المسارات المحلية مباشرة من المتصفح؛ تظهر رسالة واضحة بدلاً من الفشل الصامت. |

> هذه النسخة لا تقدّم مزامنة مؤسسية، ولا تخزيناً مشفراً مركزياً، ولا سجلاً مركزياً لتنزيل الملفات. يجب استكمال الربط المؤسسي وضوابط الخصوصية والمراجعة قبل استخدام بيانات مرضى فعلية.
