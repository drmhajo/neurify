# Neurify Redesign Concepts

This document accompanies five visual concept boards. Each board preserves the existing Neurify workflows: approved access, daily coordination, patient record viewing, clinician-reviewed reporting, report requests, and administrative monitoring. The visual mockups contain fictional, de-identified placeholder content only.

| Concept | Visual direction | Primary strengths | Screen set shown |
| --- | --- | --- | --- |
| 01 — Clinical Command | Warm white, indigo, and jade; disciplined clinical hierarchy | High trust, direct task scanning, simple adoption for current users | Sign in, Today, Medical record, Report request, Overdue reports |
| 02 — Midnight Neuro | Charcoal and deep navy with restrained cyan | Strong night-use contrast and focus for busy on-call environments | Sign in, Today, Medical record, Report request, Overdue reports |
| 03 — Human Care | Cream white, sage, and terracotta | Calmer, more approachable documentation experience with generous spacing | Sign in, Today, Medical record, Report request, Overdue reports |
| 04 — Glass Clarity | Ice blue and frosted layers with royal blue | Contemporary visual depth while preserving clinical readability | Sign in, Today, Medical record, Report request, Overdue reports |
| 05 — Surgical Canvas | White, near-black, cobalt, and safety green; editorial grid | Fast operational scanning and a distinct, minimal professional system | Sign in, Today, Medical record, Report request, Overdue reports |

## Selection guidance

Choose **Clinical Command** if the priority is continuity, clarity, and safe use in a mixed Arabic/English clinical environment. Choose **Midnight Neuro** for an intensive, high-contrast operational appearance. Choose **Human Care** when a more reassuring and spacious user experience is preferred. Choose **Glass Clarity** for a more contemporary premium visual treatment. Choose **Surgical Canvas** for the most minimal and operationally focused redesign.

## Implementation boundary

These boards are visual design concepts only. Selecting a concept does not change roles, data access, report approval rules, notification targeting, or patient-data safeguards. The chosen direction would be applied to the existing React Native screens after approval.

## Lightweight visual validation

The **Clinical Command** board visibly presents five portrait screens—sign in, daily dashboard, medical record, report request, and overdue-report monitoring—in a clear indigo/jade clinical system. The **Midnight Neuro** board presents the same five-screen scope in a distinct high-contrast navy/cyan system. Both boards retain English as the dominant language while indicating bilingual support, safe spacing around the camera cutout, and an operational bottom navigation pattern.
